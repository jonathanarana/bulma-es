Grupo de Botones

También puede usar la clase buttons (o su equivalente botones) para agrupar botones:

Inglés
<div class="buttons">
  <button class="button is-primary">Primary</button>
  <button class="button is-info">Info</button>
  <button class="button is-success">Success</button>
</div>
Español
<div class="botones">
  <button class="boton es-primario">Primario</button>
  <button class="boton es-info">Info</button>
  <button class="boton es-exito">Éxito</button>
</div>
